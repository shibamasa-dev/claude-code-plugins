# Gemini Code Assist（id: `gemini`）

| 項目 | 中身 |
|---|---|
| bot のアカウント名（login と完全一致） | `gemini-code-assist[bot]` |
| 起動のしかた | GitHub App の設定で PR 作成時に自動。こちらから頼むときはコメント `/gemini review` |
| 完了の合図 | レビュー（COMMENTED） |
| 「指摘なし」の合図 | 記録なし |
| レート制限・上限の合図（未レビュー） | 記録なし |
| 待ち時間 | 記録なし |
| 重い指摘 | Critical・High 相当で数える（重大度の書き方はツールごとに違う） |
| 再レビューの頼み方 | コメント `/gemini review`（ほかのツールへの依頼と 1 コメントにまとめる） |
| 手元で回すコマンド | なし |
