# hr

[English](README.md) | 日本語

**日本向け。** 日本の会社の人事・労務の事務を扱うスキル群（様式・法令・用語は日本のもの）。今は `employee-certificate` の 1 つだけ。会社が社員に出す証明書を作る。

## 導入

```text
/plugin marketplace add shibamasa-dev/claude-code-plugins
/plugin install hr@shibamasa-plugins
```

入れたら会社フォルダを用意する（「設定」を参照）。初めて必要になったとき、スキルがひな形からファイルを作るか聞く。

## スキル

| スキル | 使いどころ |
|---|---|
| `employee-certificate` | 保育園・学童の申込みに付ける就労証明書、在籍証明書、退職証明書、収入証明（給与支払証明書）。実体は `skills/employee-certificate/scripts/certfill.py`（Python・標準ライブラリだけ） |

## employee-certificate の動き

1. 証明書を求めた先（市区町村など）の最新の様式を探す。先方のメモを先に読み、次に先方の公式サイトを見る。ダウンロードの前に URL と日付を伝える。多くの市区町村はこども家庭庁の標準的な様式を使っているが、年ごとに少しずつ違う。
2. 様式をセル番地ではなく項目名で対応づける（`certfill.py inspect` と `read`）。レイアウトが変わっても去年の対応づけがそのまま使える。
3. 会社と社員のファイル、去年の控えから埋められるものを埋め、去年から引き継いだ値を伝える。
4. 本人しか知らないことを 1 回でまとめて聞く: 証明日、直近 3 か月の就労実績、雇用の形態（役員・自営業主など普通の雇用でないとき）、休業、子どもと施設。
5. 記入したコピーを書き出す（`certfill.py fill`）。変えるのは対象のセルだけなので、様式のプルダウンやチェック欄は壊れない。書いたあと読み戻して確かめる（`certfill.py verify`）: 各値が項目名どおりの場所にあり、ほかは何も変わっていない。
6. ファイルを渡す。最終版の保存・押印・提出は利用者がする。

退職証明書には、本人が求めた事項だけを書く（労働基準法 22 条 3 項）。

## 設定

`userConfig` のキー。プラグインを有効にするとき、または後から `/plugin` で設定する。

| キー | 既定値 | 意味 |
|---|---|---|
| `company_dir` | 空（`~/.claude/company`） | 会社フォルダ |

### ファイルの置き場所

| 何を | どこに |
|---|---|
| 部門プラグインすべてが読む会社の基本情報 | `<company_dir>/company.md` |
| 社員 | `<company_dir>/hr/employees/<key>.md` |
| 市区町村・提出先ごとのメモ（様式のページ・期限・提出方法） | `<company_dir>/hr/municipalities/<name>.md` |
| 発行した証明書の控えと、そのときの対応づけ | `<company_dir>/hr/issued/<year>/`（任意） |
| ダウンロードした様式と記入済みの下書き | 作業フォルダ、または指定したフォルダ |

プラグイン自身はデータを持たない。プラグインのデータディレクトリには何も置かず、アンインストールしても利用者のファイルは消えない。会社フォルダをどのプラグインの外にも置くのは、ほかの部門プラグインも同じ `company.md` を読めるようにするため。ファイルのひな形は `skills/employee-certificate/references/data-files.md`。

## 範囲: hr と finance

その書類を誰が発行するかで決める。会社が社員に出す証明書と、年末調整の書類を社員から集める作業は `hr`。帳簿付けと税務署への届出・申告は、今後作る `finance` プラグインに入れる。

## 制約

- 扱えるのは `.xlsx` の様式だけ。`.xls` は先に `.xlsx` で保存し直す。PDF しか無い様式や紙の様式は、手書き用に値の一覧を渡す。
- 項目名は、NFKC 正規化して空白を除いたうえで完全一致、だめなら一意な前方一致で探す。市区町村が項目名を変えたら対応づけも直す必要がある。そのとき `read` は推測せずエラーで知らせる。
- 様式探しは先方のサイト次第。ログインが要る、どれが最新か見分けられないときは、ファイルを渡すよう頼む。
- 押印・署名・印刷・提出はしない。

## 動作環境

- Python 3.9 以上（標準ライブラリだけ）

## テスト

```bash
bash plugins/hr/tests/run-all.sh
```

オフラインで動く。フィクスチャは、こども家庭庁の標準的な様式と簡易版（公共データ利用規約 第1.0版、公開されたまま）、簡易版に架空の値を記入したコピー 1 つ、架空の会社・社員データ。詳細は `tests/fixtures/SOURCE.md`。
