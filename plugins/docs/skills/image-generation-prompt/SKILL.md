# 画像生成プロンプトの組み立て

**経路を選ぶ前に、まずここで指示文を構造化する。** 経路の優先順位そのものは、ユーザーのルールファイル（画像生成の経路を定めたもの。あれば）が持つ。このスキルは「何をどう書くか」だけを扱う。

以下は GPT Image 2 世代のモデル（codex の image2、OpenAI Image API、fal.ai 経由の同モデル）で検証された作法。Gemini など他系統でも構造化の効果は共通だが、細部（文字描画の強さ、参照画像の枚数上限）はモデルで異なる。

## 5セクション構造

```text
Scene: 環境、光、時間帯
Subject: 主題（誰が/何が、どこで何をしているか）
Important details: 素材、質感、ライティング、カメラアングル、ムード
Use case: 雑誌のエディトリアル写真 / 製品モックアップ / UI画面 / 図解 など
Constraints: 透かし無し、ロゴ無し、顔を保持、被写体は1人 など
```

**5番目が最も落としやすく、最も効く。** 境界を示さずにアイデアだけ渡すと、モデルは「後悔する方向に」創造的になる。

## 6つの原則

1. **視覚的事実を書く。称賛語を書かない。**
   「stunning / masterpiece / 8K / award-winning」→「曇天光、ブラッシュドアルミ、柔らかいバウンス光、50mm 相当」

2. **スタイル語には視覚的な着地点を添える。**
   「ミニマル・ブルータリスト」→「クリーム地、太いブラックサンセリフ、非対称の文字塊、大きな余白」

3. **そのものの名前を言う。**
   ムード語でなく「改札機」「搭乗券」「顔を保持」と具体名詞で書く。

4. **編集では「変える」と「保つ」を分離する。**

5. **文字はタイポグラフィとして扱う。**
   リテラルは引用符か ALL CAPS で囲み、書体・サイズ・色・配置を指定する。

6. **1ターン1改訂。** 小さな反復が大きな書き直しに勝る。

## 3つのモード

### 生成

5セクション構造をそのまま使う。用途別の具体的な書き方は [references/patterns.md](references/patterns.md)。

### 編集（inpaint・背景差し替え・天候変更・服の変更）

```text
Change: 変えるものだけを正確に
Preserve: 顔、同一性、ポーズ、光、フレーミング、背景
Constraints: 余計な物を足さない、透かし無し
```

さらに**物理的な整合**を1文加える — ライティングの一致、接地影、パースの整合。

### 複数画像の合成

各入力に役割ラベルを付け、指示文からラベルを参照する。

```text
Image 1: 保持するベースシーン。
Image 2: ジャケットの参照。
Instruction: Image 1 の人物に Image 2 のジャケットを着せる。
顔・体型・ポーズ・背景・光は Image 1 のものを保持。
```

参照画像は最大16枚（GPT Image 2 系）。**必ず全部に役割を与える。**

## 画像内の文字

このモデル系統の最大の強み。崩さないための書き方:

- 正確な文字を引用符で囲む — `看板には "GRAND OPENING" と書かれている`
- または ALL CAPS でリテラルを示す — `カップの文字: HELLO WORLD`
- 書体を指定 — `太いセリフ` `コンデンスドサンセリフ` `手書き風`
- 配置を指定 — `上部3分の1の中央` `左下隅`
- `余計な単語を入れない` `文字を重複させない` を Constraints に入れる
- それでも崩れるなら1文字ずつ綴る — `"X-R-A-Y"`

## 弱い例と強い例

**弱い:**
```text
A stunning ultra-detailed cinematic masterpiece of a woman in a museum,
beautiful, photoreal, 8K, award-winning.
```

**強い:**
```text
Scene: 美術館のギャラリー、午後遅く、柔らかい頭上スポット。
Subject: チャコールのウールコートを着た30代の女性が、大理石の胸像から
  3メートル離れて立ち、横目で作品を見ている。
Important details: 50mm相当、浅い被写界深度、ニュートラルなクリーム色の壁、
  胸像に温かいタングステン、彼女の顔には冷たいアンビエント。
Use case: 雑誌のエディトリアル写真。
Constraints: 透かし無し、ロゴ無し、過度なレタッチ無し、被写体は1人にフォーカス。
```

## 複数枚を1つの成果物に入れるとき

**スタイルテンプレートを共有する。** 背景・配色・線の太さ・字体の指定を1つのテンプレート文に固定し、各画像で使い回す。変える軸は1枚につき1つ。
